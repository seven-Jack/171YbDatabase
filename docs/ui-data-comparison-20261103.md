# M6 数据检索与同条件比较

本地实现基线为已发布的`31db0b9acca7bd87c9e07e61d6886691e90e7135`，分支`codex/m6-transition-comparison`。原实现阶段仅做本地验收；本次交付包含提交、推送、创建PR并确认CI，不包含合并与公开发布。M1–M5原有功能保留。

## 检索

仅在核心数据表上方增加搜索及默认折叠筛选，不恢复主跃迁图下方已删除的T1/T2目录。复用现有检索模型，支持波长、态名、用途和矩阵元证据文本；`556`只是`555.80068663`的整数检索别名，原波长数据不变。普通字符、上下标和全角输入统一匹配。

波段、跃迁类别与矩阵元证据可组合筛选；后者不代表波长证据或独立实验验证状态。排序和主要／全部字段切换沿用原表格，筛选不影响其他三个数据类别、主图或当前计算。空结果明确显示，重置可恢复。比较列表独立保存，搜索隐藏某条记录时不将其移出比较。

## 同条件比较

最多三条，直接复用当前有效计算对象的规范化原子处分量功率`Pq`、1/e²强度半径`w₀`与实际通道。自动选择先解析为明确的`(F,mF,F′,mF′,q)`，再对所有目标严格查找同一五元组；目标不存在该通道时不给出Rabi数值，不能偷偷换F或最强分量。

每条跃迁通过自己的ID读取canonical矩阵元、约定和电子角动量，复用`computeCGChannels`与`calculateRabi`。J约化和有效F约化分别处理，保留原记录。T4继续不适用通用单光子E1模型，R2沿用其既有参数与未接入证据状态；不借用其他跃迁的已核结论。

当前输入无效、规范化不一致或没有实际允许通道时，全部比较结果清除，不能继续展示旧数值。零功率仍可显示零频率。频率显示单位与当前计算器一致，所有比较条目使用相同单位。波长旁的来源小标只对应波长；采用矩阵元的来源单独显示在`d_eff`说明中。原记录参数与来源默认折叠，各条证据按自己的实际上下文重建。

## 状态与载入

检索、排序和添加／移除比较只读当前计算，不修改主图选择、M1输入、M2/M4证据或M5导出对象。“查看分量”是明确的跃迁切换；“载入此工作点计算”只对有效条目启用，将完整通道、M1录入定义／原值及规范化Pq/w₀一起交给既有配置接口，进入Rabi区并更新顶部标记。载入后M5导出当前对象，未载入的比较条目不混入导出。
