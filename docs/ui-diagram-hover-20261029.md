# 主跃迁图悬浮信息与超精细结构优化

界面修订：`quantum-hover-20261029.1`

## 展示方案

- 悬浮于跃迁线：显示态对、真空波长、频率、矩阵元及其约化层级、多极性。移除能级寿命、未厘清的线宽表达、振子强度与大段说明。
- 悬浮于能级：在该能级旁显示组态、J / I / 宇称、能量与已收录寿命，以及该态的零场超精细结构。
- 保留鼠标悬浮触发，允许移入卡片阅读或点击来源；能级支持键盘聚焦，触屏支持点按与关闭。滚动页面时关闭旧浮层，避免与目标位置脱离。
- 主图八条跃迁、能级与跃迁线坐标、原有配色和筛选保留。

## 超精细结构

- 使用深蓝黑卡片、暖金与冷蓝 F 能级线，单独显示 A 和 Δν；位移以 δE/h（MHz）标注。
- 各 F 支按能量高低排列，保留负 A 态的真实顺序。
- B=0 时，同一 F 内 mF 简并；以简洁标签列出 mF 和态数，删除原先容易被误读为实际塞曼分裂的扇出线。
- J=0 / F=1/2 显示 2 重简并，修正旧面板的“1”展示错误；不改变底层数据。
- 65S 保留保存数值的六位小数、有效 A 与“所选 F 对重心”口径；估算能量使用 ≈ 标识。
- 320px 手机宽度下，较长的 65S 数字卡片改为上下排列，避免溢出。

## 来源小标

数据值右下角使用可点击的 `[n]` 小标；编号指向页尾对应来源条目。

原有文献沿用 [1]–[17]。另列 [18]–[23] 六项原有数据记录，包括能级、超精细结构、标度估算、T2 内部校准、T3 内部补充及 65S 零场保存数据。点击小标自动展开并定位数据记录。文献与内部记录不合并，所有原有待重核状态保留。

例如 T2 波长指向 [1]，其校准矩阵元指向 [21]；65S 的超精细数值指向 [23]，与矩阵元记录 [17] 分开。
