## 修改

- 删除主图下方八张 T1–T7 / R2 选择卡片，以及仅用于卡片的目录检索、排序、筛选与比较入口。
- 点击主图中的跃迁线或波长标签，选中该跃迁，关闭悬浮详情，跳转到 `#secCalc`，并将键盘焦点移到“超精细分量”标题。

- 使用浏览器历史记录保存跳转，后退可返回主图；重复停留同一工作区时不堆叠相同锚点。
