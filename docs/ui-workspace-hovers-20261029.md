## 交互与定位

- 优先放在当前 SVG / canvas / 表格区域之外；空间不足时选择遮挡较少、且不覆盖触发目标的位置。SVG 连线与文字参与避让。
- 同一张图内移动时，悬浮卡位置保持稳定，读数更新；切换目标或窗口尺寸改变时重新定位。
- 鼠标移入卡片可继续阅读及点击上标；离开延迟 380ms 关闭；键盘聚焦、Escape 关闭和来源跳转已接入。
- 共用悬浮卡一次只显示一个内容，避免主图、工作区和数据表提示混用样式。
