# 架构与责任边界

本项目是静态科研数据展示和浏览器计算工具，继续通过 GitHub Pages 发布。主页完整能级图、全部 8 条跃迁与连续三步操作是产品约束。

## 模块

- `data/`：结构化科学记录、来源、条件、约定与数据版本；缺失保持缺失。
- `src/data/`：加载和适配 canonical 数据。旧显示字段仅用于兼容，不能另建科学数值副本。
- `src/physics/`：常数、单位、角动量、Rabi 与隔离的估算模型。纯函数不访问 DOM。
- `src/state/`：当前跃迁、通道、输入、结果状态和版本化配置；状态修改经过明确入口。
- `src/ui/`：图、表、输入、详情和图表呈现。消费正式计算接口，避免复制公式。
- `src/styles/`：字体、颜色语义、间距与响应式布局。
- `scripts/`：数据校验/导出、构建、发布产物检查和显式同步动作。
- `tests/`：数据、纯计算、状态、构建与浏览器用户路径。

加载依赖应通过 imports 和初始化参数表达。组件不能靠定时重试猜测另一模块已启动；订阅失败应能定位。切换跃迁时重新判断通道有效性，图、表、结果使用同一个选择。

研究记录由 `src/ui/calculation-record.js` 组合现有配置重算接口、实际通道与证据视图；格式化不实现另一套物理公式。`calculation-record-controls.js` 只负责本地下载和导出可用性。研究记录与配置拥有不同的 `kind` 和格式版本，嵌套配置仍沿用 v2；恢复入口只提取配置交给现有解析器，保存的证据状态不会导入当前计算状态。

数据区的 `data-browser.js` 复用 `explorer-model.js` 检索现有核心表格，过滤经表格的显式接口重新渲染，不操作主图。比较选择独立于检索和计算器；`equal-condition-comparison.js` 从canonical数据重建每条跃迁，严格匹配当前实际通道的完整五元组，调用既有CG、Rabi及证据接口。不使用跨跃迁最强通道回退，不另写物理公式。仅显式载入比较工作点时，才把该行的完整状态交给既有图表配置接口；M1录入定义和规范化参数一起保留。M5导出对象不包含未载入的比较条目。

## 外部计算

MQDT 求解代码、远端任务和原始 Run 证据继续在计算工作区维护。网站导入经过整理的版本化发布数据，不承担远端求解或研究进度管理。原始论文/Run 不随静态站自动公开。

## 发布产物

软件版本只在 `package.json` 维护。预检和构建生成 Git 忽略的 `src/version.js`，供源预览和发布页面共同导入；公式版本由正式 `constants.js` 的 `FORMULA_VERSION` 导出，数据版本由数据发布清单提供。

工作点CSV和摘要消费既有研究记录；图表导出消费正式绘图过程产生的快照，不实现第二套物理核。图表序列化器仅在导出时动态加载。构建按真实静态模块依赖生成head预加载链接；源index和图内DOM不变，启动入口的阶段计时与恢复不承担科学计算。

构建只清理本仓库的 `dist/`，复制实际入口、模块、数据与资产。`build-info.json` 记录软件、提交、工作区、数据与公式版本；`artifact-manifest.json` 记录文件和 SHA-256。版本可追溯不等于相关模型已得到实验验证。
