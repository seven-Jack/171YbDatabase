# 科学数据维护规则

## 记录与来源

每个核心物理量记录数值、单位、矩阵元/物理量约定、条件、来源、证据类型、原文核查状态和不确定度。来源集中登记，字段分别引用；整行中的波长、寿命和矩阵元可能来自不同证据。

文献测量、文献理论、保存的本工作计算、简化估算和派生量分别标明。原文定位状态、内部一致性、固定模型数值收敛和实验/物理验证分别记录；不能合并为一个“已验证”。保存位数不是实验精度，未知不确定度不能写成零。

同一数值的页面与 CSV 由同一数据源生成。独立测量的波长、频率、能量仍保留原值及各自精度；有差异时记录冲突，不能为了整齐强行覆盖。

## 修改顺序

1. 找到原始论文、数据发布版或保存的计算记录，核对具体态与实验/模型条件。
2. 列出字段、旧值、新值、定义、来源定位和差异原因。
3. 更新 canonical 数据、必要的派生关系与来源记录；运行相关检查。
4. 审阅页面、导出、版本与差异证据。未解决的冲突保持待核查。

## 重点约定

- 能级：同位素、稳定态 ID、组态、量子数、零点和阈值；混合态归属不能只靠名称。
- 矩阵元：区分 J/F 约化量和具体 mF 通道量，保留相位/符号与单位。
- 寿命/线宽：分别记录寿命、衰减率和普通频率线宽，关系式仅在定义与通道适用时使用。
- 65S：保留三重态关联根、零场条件、能量参考和有效 A 的适用范围。内部关系检查不能代替分支证据或独立实验。
- 估算：记录模型与适用范围，缺失正式数据不静默回退到估算。

本轮先迁移 T2/T3/R2 和 65S 核心记录。其他旧条目可保留显示，但缺失出处必须标记 `legacy/pending`，不得批量升级核查状态。
