# 图轴内编辑 · 2026-10-29

两张 Rabi 图删除重复跃迁标注及独立轴设置框。当前跃迁和 F/mF 通道继续由顶部吸顶标记显示。

- 四个最大值输入位于各自坐标轴末端，显示实际绘制上限；直接编辑后回车或失焦提交，清空恢复自动。
- 功率、频率、束腰单位选择位于轴标题括号内，以细下划线提示可点击。
- 两图功率单位同步，独立的热图功率上限随单位等价换算；热图束腰上限内部仍用 µm 保存，显示单位支持 µm/mm/nm。
- 最大值必须有限并大于当前下限，非法值保持上一有效范围并在图内提示；对数轴保留正下限校验。
- 自动模式与显示数值独立保存，避免显示出的自动上限被误写为手动范围。Enter 显式提交并防止同步 blur/change 重复提交。
- 只改变图轴显示状态，不更新计算输入或选定通道。最大值框继续使用滚轮保护。
- 窄屏减少刻度密度避免与端点编辑重叠。绘图容器采用 overflow:clip，防止聚焦控件导致内部滚动并错开画布。
