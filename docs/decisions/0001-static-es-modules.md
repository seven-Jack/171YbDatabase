# ADR 0001：静态发布与原生 ES Modules

日期：2026-10-26。状态：本轮采用。

项目主要由静态科学记录、SVG/Canvas 图形和浏览器内轻量计算组成。已有 GitHub Pages 部署和领域交互可以继续使用，当前维护压力来自职责混排和检查覆盖不足。

本轮采用原生 JavaScript ES Modules，按数据、物理函数、状态和界面分开；继续使用轻量 Node 构建。Playwright 仅为开发测试依赖，网站运行不加载它。

这一选择保留现有部署方式，同时使正式函数可被 Node 测试导入。代价是必须显式维护模块依赖和正确的相对资源路径，使用 HTTP 预览，并在仓库 Pages 子路径检查构建产物。

后续只有在明确维护成本支持时再评估 Vite/TypeScript 或 UI 框架。新增依赖应说明替代的复杂逻辑、构建负担和退出方案。
