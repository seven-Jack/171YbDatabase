# mF 通道直达 Rabi · 2026-10-29

点击超精细分量图中的通道连线，或 CG 表的 mF 按钮后，先选定通道并完成重算，再进入 Rabi 计算区。顶部原有吸顶标记继续显示当前跃迁、F/mF → F′/mF′ 和偏振。

- 普通 E1 与超精细诱导钟跃迁共用选择完成回调。
- 重复选择同一通道保留手动选定状态；需要调整时可返回超精细分量区。
- CG 表 Enter/空格操作同样跳转，并将焦点移至 Rabi 标题。
- 点击后关闭原通道悬浮提示，滚动避开顶部导航与状态条。
- 跳转保留浏览器返回路径；重复进入当前 Rabi 锚点不追加重复历史。
- 普通输入修改、偏振切换、F 显示筛选、默认初始化和配置恢复不触发通道跳转。
