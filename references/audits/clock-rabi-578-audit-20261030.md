## 2. 当前矩阵元有没有重复乘CG？

生产程序采用有效F约化量dF，不是电子J=0→J′=0的裸E1约化量：

```text
<F′m′|d_q|Fm> = CG(Fm;1q|F′m′) × dF / sqrt(2F′+1)
F=F′=1/2:
|d_pi| = |dF|/sqrt(6)
|d_sigma| = |dF|/sqrt(3)
```

固定一个上态m′，π和σ两个辐射通道满足：

```text
sum_final_m,q |d_q|² = dF²/2
A_HFQ = omega³ (dF*ea0)² / [3*pi*eps0*hbar*c³*(2F′+1)]
```

因此`dipoleFromDecayRate(A,lambda)`返回的是`dF/sqrt(2)`，不是dF，也不是固定π通道矩阵元。转换到dF乘√2，转换到π通道则除√3；当前专用F约化分支正确，没有再做J→F换算。所有通道平方和及正反关系均已测试。

用当前dF=9.19×10⁻⁵ea₀：dπ=3.751801789×10⁻⁵ea₀、dσ=5.305848974×10⁻⁵ea₀，隐含自由原子HFI率0.0442118532/s、寿命22.61837s。

### 新找到的独立强度来源

C.-Y. Xu et al., *Measurement of the Hyperfine Quenching Rate of the Clock Transition in ¹⁷¹Yb*, PRL113,033003(2014)，[DOI10.1103/PhysRevLett.113.033003](https://doi.org/10.1103/PhysRevLett.113.033003)，[全文](https://arxiv.org/pdf/1406.2340v1)。PDF pp.3–4、Eq.(2)、TableI报告自由原子A_HFQ=0.0442±0.0035/s。

实验测量固Ne中的¹⁷¹Yb/¹⁷²Yb差分衰减，并处理介质淬灭、能级移位、折射率及频率三次方，得到自由原子结果。它不是未经校正的冷原子阱内存活寿命，也不是直接实测Rabi频率。

采用该原始率得到：

```text
dF = 9.188768e-5 ea0
u(dF) = 3.6381e-6 ea0        (仅率输入的一阶传播)
d_pi = 3.751299e-5 ea0
```

当前9.19×10⁻⁵与此相差约0.0134%，明显在率推导误差内。这为数值大小和F约化约定提供了独立文献支持。

**这不等于恢复了旧内部记录的历史来源。**最早导入提交`ea024f9`已经包含旧数值：v5.7先把5.30×10⁻⁵当通用值，v5.8将其解释为σ通道锚点并乘√3得到9.19×10⁻⁵。未找到该5.30×10⁻⁵的原始计算工件。历史记录原样保留，Xu推导作为独立新证据单独登记，没有反向改写旧出处。

其他原始/汇编强度交叉检查：

| 依据 | dF/ea₀ | 同一70nW、200µm、π束心的Ω/2π |
|---|---:|---:|
| 当前内部记录 | 9.190000×10⁻⁵ | 13.908643Hz |
| Xu2014，A=0.0442(35)/s | 9.188768×10⁻⁵ | 13.906778Hz |

Xu对应的Rabi率输入误差约0.5506Hz；这**只包含原子率→矩阵元传播**，不包括未知功率/束腰及动力学误差，不能作为完整实验比较误差条。

Porsev & Derevianko，[PRA69,042506(2004)](https://doi.org/10.1103/PhysRevA.69.042506)，本地arXiv PDF p.8 TableIV。Kroeze推荐值依赖Xu及Siegel2024：[PRL132,133201](https://doi.org/10.1103/PhysRevLett.132.133201)、[全文](https://arxiv.org/pdf/2402.04968v2)，pp.4–5 Fig.5用Γtot=Γ0+γL Ueff分离晶格淬灭和背景损失，得到自然寿命19(2)s。它不是可直接用有限阱深总衰减替代的寿命；Kroeze也不是第三个独立实验。替换成推荐寿命会让裸Rabi略升，不能解释降到8.33Hz。

## 3. 差异的数值要求

高斯束心的正式计算为：

```text
I0 = 2P/(pi*w0²) = 1.11408460 W/m²
fR = Omega/(2*pi) = |d_pi| E0/(2*pi*hbar) = 13.9086427105 Hz
t_pi = 1/(2*fR) = 35.9488708142 ms
```

原文60ms名义π时间对应8.333333333Hz，所需幅比为0.599147847，当前裸结果比该名义值高66.9037%。这里没有完整联合误差预算，不能把它当作严格显著性检验。

如果其余项全都精确，单独改变一项以达到名义值，分别需要：

| 被改变的量 | 代数要求 | 是否采用 |
|---|---:|---|
| 功率 | 25.12847nW，代替原文70nW | 否，未测得该损耗/功率 |
| 1/e²束腰半径 | 333.80743µm，代替原文200µm | 否，原文不支持 |
| dF | 5.506169×10⁻⁵ea₀ | 否，无独立强度证据 |
| 上述dF隐含寿命 | 63.00765s | 否，不是Xu或推荐自然寿命 |

这些只是灵敏度/反事实数值，绝不是新实测输入，也不是“反推矩阵元再验证自己”。给全站乘0.599修正因子没有依据。

## 4. 运动和光场能否解释？

Pizzocaro引用的S. Blatt et al., *Rabi spectroscopy and excitation inhomogeneity in a one-dimensional optical lattice clock*, [PRA80,052703(2009)](https://doi.org/10.1103/PhysRevA.80.052703)，[arXiv v2](https://arxiv.org/pdf/0906.1419v2)，pp.5–6 Eqs.(14)–(20)给出运动态依赖载波及热平均人口模型。该文章的实验体系是⁸⁷Sr；这里仅使用通用谐振子数学关系，不把Sr参数移入Yb。该文部分Ω符号使用普通Hz，本核查统一区分fR与角频率Ω。

### 轴向运动：可量化，但不够构成完整解释

用原文典型200Er、759nm晶格和Tz作隔离的谐振近似：νz≈57.3065kHz，ηz²≈0.0608769。

```text
Omega_n/Omega_bare = exp(-eta²/2) L_n(eta²)
<Omega_n>/Omega_bare = exp[-eta²*(nbar+1/2)]
```

| Tz | 热均有符号矩阵元幅比 | 裸耦合乘该幅比 |
|---|---:|---:|
| 4µK | 0.912105 | 12.686143Hz |
| 7µK | 0.854762 | 11.888584Hz |
| 10µK | 0.800322 | 11.131387Hz |

这些数值**不是实际振荡拟合频率**，因为Σpn sin²(Ωnt/2)不等于sin²(〈Ωn〉t/2)。无界谐振热分布本身也是近似；Tz=7µK时约6.4%的数学权重已高于名义阱顶，报告中明确保留该近似限制。

若硬让这一均幅单独达到0.599147847，需要Tz≈23.1149µK，已超过200Er对应U/kB≈19.4474µK，不应把它当作合理的深谐振态实验拟合温度。

### 径向温度与残余夹角：真正缺失的控制量

原文未给Tr和实测残余夹角。45µm晶格腰下径向约束仅约217.55Hz，因此几毫弧度夹角就可能引入显著径向运动耦合。举例固定Tz=7µK，**另行假设**Tr=4/7/10µK，使热均幅达到0.599的角度量级分别约7.61/5.75/4.81mrad。

这是展示不可辨识性的条件计算，**没有测到这些温度或角度，也没有完成实验人口曲线拟合**。不能把文中相对水平面的晶格倾角60mrad误作探针/晶格之间的残余夹角。

### 光束包络、返回光和激光噪声

若探针束心对准原子且原子位于所述r≤45µm、|z|≤0.25mm几何区域，Gaussian场包络仍约≥0.9506。普通包络变化本身不能在这些条件下产生0.599；但原文没有给出完整云分布和绝对束心标定，不能把区域描述当作无条件严格边界。

同模、同束腰的返回场若R<1%，其幅度小于入射场0.1，可造成约±10%的局部相干场变化。**这一结论要求返回光模式相同**；原文未给578nm返回束腰、模式和相位，所以不能只凭镜面功率反射率无条件排除聚焦或局部干涉影响。完整等幅驻波的2P/4I仍不成立。

18–20Hz是光谱宽度，没有分解为傅里叶响应、功率/运动展宽和不同时间尺度的激光噪声。不能直接把它塞入Markov退相干模型来“修正”Rabi。删除CG、额外乘除√2/√3/2π、或将峰值强度任意减半，也没有原文依据。

能够确认：原文200µm为半径；70nW不是光源总输出；π偏振无须分功率；F约化与mF角因子正确；当前矩阵元由独立HFI率推导得到支持；主图和正式计算无需为该单一操作点加入经验修正。

**仍不能确认唯一物理原因或宣布独立Rabi实验验证通过。**需要以下同一操作点信息才能关闭差异：

1. 原子处绝对功率、偏振/模式重叠及误差。
2. 原子处束腰与对准测量及误差。
3. 人口随脉冲时间的原始数据、拟合模型和误差，而不只有一个名义π时间。
4. Tr、轴向/径向运动分布及探针残余夹角。
