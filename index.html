查看推导

高斯光束的强度分布为 I(r)=I0exp(−2r2/w02)。

对光束横截面积分，得到总功率 P=πw02I0/2。

因此，中心强度为 I0=2P/(πw02)。

周期平均强度满足 I0=cε0E02/2，由此得到电场振幅 E0=√[4P/(πw02cε0)]。

代入 Ω=deffE0/ℏ，再除以 2π，即得到上方公式。旋波近似的哈密顿量耦合项为 ℏΩ/2，Ω 本身无需再除以 2。

选择定则

  • E1 (电偶极) ΔS=0, ΔL=±1, ΔJ=0,±1 (禁0↔0), 宇称变
  • M1 (磁偶极) ΔS=0, ΔL=0, ΔJ=0,±1 (禁0↔0), 宇称不变
  • M2 (磁四极) 秩 2 角动量三角条件；宇称变（如 J=0→2）
  • E2 (电四极) 秩 2 角动量三角条件；宇称不变
  • Yb 的 4f¹⁴ 闭壳层使 LS 耦合近似较好但非完美：³P 与 ¹P 间的自旋-轨道混合使"自旋禁戒"的 intercombination 线仍可被 E1 激发，振子强度下降 ~2 个量级。

超精细结构

  • ¹S₀：J=0 → A_hfs = 0，仅 F=1/2，无超精细分裂
  • A(³P₁) = MHz
  • A(³P₂) = MHz
  • A(³S₁) = MHz
  • A(³D₁) = MHz
  • A(¹P₁) = MHz
  • 离子实 A(6s ²S₁/₂) = 12.643 GHz
  • ¹⁷¹Yb (I=1/2) 里德堡态收敛于两个电离阈，对应 Yb⁺ 的 F_core = 0 和 F_core = 1。

里德堡要点

  • 实验上主要从 ³P₂ 亚稳态经 325 nm 单光子 激发至 n³D_J 里德堡态 (Wilson 2022)
  • 6s75s ³S₁ 态 C₆ 已实验测量，阻塞半径 ~μm 量级 (Wilson 2021)
  • 奇宇称里德堡态存在 p-f 混合，是 ¹⁷¹Yb 特有现象 (Kuroda 2025)
  • 高 n 态需使用 MQDT 多通道 模型描述，简单单通道量子亏损公式有偏差
  • 典型 n = 50–80，寿命 50–400 µs，轨道半径 0.3–0.9 µm
  • CZ 两比特门保真度可达 0.994(1) (Peper 2024)
